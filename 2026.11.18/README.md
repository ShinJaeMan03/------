# 2026.11.18 풍속 강풍 분류 실습

`wind_dataset.csv`의 1시간 뒤 풍속을 이용해 강풍 여부를 분류하고, 2024년 12월 평가 데이터에서 기준 예측과 로지스틱 회귀를 비교한 실습입니다.

## 입력 데이터

- 원본 파일: `..\2026.11.11\wind_dataset.csv`
- 시간 기준: KST
- `prediction_time`과 `target_time`은 정확히 1시간 차이
- 행은 시간순으로 검사

현재 폴더에 입력 파일이 있으면 그 파일을 우선 사용하고, 없으면 `2026.11.11\wind_dataset.csv`를 사용합니다.

## 분류 기준과 데이터 분할

- `wind_speed_target >= 4.0 m/s`: 강풍 `1`
- `wind_speed_target < 4.0 m/s`: 강풍 아님 `0`
- 학습: 정답 시각 기준 2023년 1월 1일 ~ 2024년 11월 30일
- 평가: 정답 시각 기준 2024년 12월 1일 ~ 2024년 12월 31일

데이터 개수:

- 학습: 16,720행 (`0`: 15,427행, `1`: 1,293행)
- 12월 평가: 744행 (`0`: 705행, `1`: 39행)

## 파일

- `classify_wind.py`: 분류, 로지스틱 회귀, 평가 점수와 그래프 생성
- `2026.11.18.py`: 풍속 수치 예측 실습 코드
- `classification_predictions.csv`: 12월 평가 행별 실제값과 예측 결과
- `classification_scores.csv`: 방법별 평가 점수와 혼동행렬 수
- `strong_wind_december.png`: 12월 1~7일 시간 그래프

## 예측 방법

`classify_wind.py`는 다음 방법을 같은 12월 평가 데이터에 적용합니다.

1. 항상 0
2. 현재 풍속이 4.0 m/s 이상이면 1로 예측
3. 현재 풍속, 기온, 습도, 1시간 전 풍속, 2시간 전 풍속을 입력으로 사용한 로지스틱 회귀

로지스틱 회귀는 학습 데이터만으로 표준화하고 학습하며, 확률 판정 기준 `0.50`과 `0.20`을 모두 계산합니다. 1시간 뒤 실제 풍속은 입력 특성에 포함하지 않습니다.

## 실행

저장소 루트에서 실행합니다.

```powershell
python ".\2026.11.18\classify_wind.py"
```

실행하면 `classification_predictions.csv`, `classification_scores.csv`, `strong_wind_december.png`가 갱신됩니다.

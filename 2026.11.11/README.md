# 풍속 예측 실습

`asos_108_2023_2024.csv`를 이용해 다음 실습을 수행합니다.

- 관측 시각을 1시간 간격으로 맞추고 입력·정답 데이터셋 생성
- 현재 풍속 유지 기준 예측과 선형회귀 비교
- 랜덤포레스트 앙상블 비교
- 2024년 12월 1일~7일 예측 그래프 생성

## 실행 방법

`asos_108_2023_2024.csv`를 이 파일과 같은 폴더에 둔 뒤 실행합니다.

```powershell
python 2026.11.11.py
```

그래프를 만들기 위해 `matplotlib`이 필요합니다.

```powershell
python -m pip install matplotlib
```

## 생성 파일

- `wind_dataset.csv`: 입력 5개와 1시간 뒤 풍속 정답을 한 행에 저장
- `predictions.csv`: 2024년 12월 평가 구간의 실제값과 세 가지 예측 저장
- `prediction_week.png`: 12월 1일 00시부터 7일 23시까지의 예측 비교 그래프

## 데이터 구성

선형회귀와 랜덤포레스트의 입력은 다음 5개입니다.

1. 현재 풍속
2. 1시간 전 풍속
3. 현재 기온
4. 현재 습도
5. 2시간 전 풍속

정답은 정확히 1시간 뒤의 실제 풍속입니다. 학습과 평가는 시간순으로 분리하며, 2024년 12월 전체를 평가 구간으로 사용합니다.

## 실행 결과

동일한 12월 평가 자료 744개에서 측정한 MAE는 다음과 같습니다.

| 방법 | MAE |
|---|---:|
| 현재 풍속 유지 기준 | 0.653495 |
| 선형회귀 | 0.594577 |
| 랜덤포레스트 | 0.593158 |

랜덤포레스트 설정은 `n_estimators=100`, `max_depth=6`, `min_samples_leaf=5`, `random_state=42`입니다.

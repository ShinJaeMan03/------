# 코딩과 응용 Python 프로그램

이 폴더에는 힘 단위 변환 프로그램과 원형 봉의 축응력 계산 프로그램이 들어 있습니다.
코드에서 확인할 수 있는 기능만 정리했습니다.

## 필요한 환경

- Python 3
- `tkinter` 및 `tkinter.ttk`
  - GUI 프로그램 실행에 필요합니다.
- CSV 분석기에는 `pandas`와 `matplotlib`가 필요합니다.
- 힘 단위 변환기와 원형 봉의 축응력 계산기는 외부 Python 패키지를 사용하지 않습니다.

## 프로그램 목록

### 1. 힘 단위 변환기

파일:

- `2026.09.14/force_converter.py.py`
- `2026.09.23/force_converter.py1.py`

두 파일 모두 Tkinter GUI로 동작합니다. 입력한 힘을 `kN`, `N`, `kgf` 중 선택한 단위에서 다른 단위로 변환하고, 결과를 `kN`, `N`, `kgf`로 표시합니다.

변환에는 다음 관계가 사용됩니다.

- `1 kN = 1000 N`
- `kgf` 변환에는 `9.81`을 사용합니다.

`2026.09.14/force_converter.py.py`는 계산 함수가 GUI 위젯을 직접 참조합니다. `2026.09.23/force_converter.py1.py`는 계산 및 초기화 함수에 GUI 위젯을 인자로 전달하는 형태로 작성되어 있습니다.

#### 실행 명령

작업 폴더의 PowerShell에서 다음 중 하나를 실행합니다.

```powershell
python ".\2026.09.14\force_converter.py.py"
```

```powershell
python ".\2026.09.23\force_converter.py1.py"
```

#### 정상 입력 예시

GUI가 열리면 다음과 같이 입력합니다.

```text
숫자 입력: 2.5
단위 선택: kN
```

변환 결과는 다음 형식으로 표시됩니다.

```text
변환 결과
2.50 kN = 2500.00 N
254.84 kgf
```

#### 오류 입력 예시

입력값이 숫자가 아니거나 0보다 작은 경우 변환 결과 대신 다음 메시지가 표시됩니다.

```text
입력값: abc
메시지: 잘못된 입력입니다. 0 이상의 숫자를 입력하세요.
```

```text
입력값: -1
메시지: 잘못된 입력입니다. 0 이상의 숫자를 입력하세요.
```

### 2. 원형 봉의 축응력 계산기

파일:

- `2026.09.14/import math.py.py`

콘솔에서 축하중 `P`와 원형 단면의 직경 `d`를 입력받아 축응력의 절댓값을 MPa 단위로 계산합니다. 축하중의 부호에 따라 결과를 인장, 압축 또는 무응력으로 표시합니다.

- 축하중 `P`: `kN`, 인장 양수, 압축 음수
- 직경 `d`: `mm`, 0보다 커야 함
- 단면적: 원형 단면 기준

#### 실행 명령

```powershell
python ".\2026.09.14\import math.py.py"
```

#### 정상 입력 예시

```text
축하중 P [kN] (인장 +, 압축 - ) = 10
직경 d [mm] = 20
```

출력 예시는 다음과 같은 형식입니다.

```text
[1] 원형 봉의 축응력 (인장/압축)
축하중 P [kN] (인장 +, 압축 - ) = 10.0
직경 d [mm] = 20.0
응력 sigma = 31.83 MPa (인장)
```

#### 오류 입력 예시

숫자가 아닌 값을 입력하면 해당 입력을 다시 요구하고 다음 메시지를 표시합니다.

```text
축하중 P [kN] (인장 +, 압축 - ) = abc
숫자를 입력하세요.
```

직경에 0 이하의 값을 입력하면 다시 입력하도록 요구합니다.

```text
직경 d [mm] = 0
직경 d는 0보다 커야 합니다.
```

### 3. CSV 하중-응력 분석기

파일:

- `2026.10.07/land_analyzer.py`

`load_data.csv`를 읽어 하중 데이터를 분석하고 응력을 계산합니다.

#### 입력 파일과 단위

- 입력 파일: `2026.10.07/load_data.csv`
- `time_s`: 시간, 단위 `s`
- `force_N`: 하중, 단위 `N`
- 단면적: `100 mm²`
- 응력 계산: `stress_Mpa = force_N / 100`

#### 필요한 라이브러리

- `pandas`: CSV 읽기와 결과 저장
- `matplotlib`: 시간-응력 그래프 생성

#### 실행 명령

작업 폴더의 PowerShell에서 다음을 실행합니다.

```powershell
.\.venv\Scripts\python.exe ".\2026.10.07\land_analyzer.py"
```

#### 출력 파일

- `2026.10.07/load_result.csv`: 유효한 입력 데이터와 `stress_Mpa` 열
- `2026.10.07/stress_plot.png`: 시간-응력 그래프

그래프에는 각 데이터 점, 연결선, 최대 응력점과 최대 응력값 주석이 표시됩니다. 또한 기준 응력 `6 MPa`를 초과한 데이터 개수를 출력합니다.

#### 오류 처리 규칙

- `time_s` 또는 `force_N` 열이 없으면 오류를 표시하고 종료합니다.
- 두 열의 값이 빈칸이거나 숫자가 아니면 CSV 행번호와 문제값을 표시합니다.
- 문제가 있는 행은 계산, 결과 CSV 저장, 그래프 생성에서 제외합니다.
- 제외한 행 수와 유효한 데이터 수를 출력합니다.
- 유효한 데이터가 없으면 계산과 그래프 생성을 중지하고 안내합니다.

### 4. 2026.10.07 파일과 오늘의 실습 기록

#### 폴더 파일

- `2026.10.07/force_converter.py3.py`: Tkinter 기반 힘 단위 변환기. `kN`, `N`, `kgf` 입력을 받아 `kN`, `N`, `kgf`로 변환합니다.
- `2026.10.07/land_analyzer.py`: CSV를 읽어 유효성 검사, 응력 계산, 최대값 출력, 그래프 생성을 수행합니다. 기본 입력은 `load_data.csv`입니다.
- `2026.10.07/load_data.csv`: 정상 원본 입력 파일입니다. `time_s`와 `force_N` 열을 사용합니다.
- `2026.10.07/load_test.csv`: 7초의 하중을 900 N으로 바꾼 테스트 입력 파일입니다.
- `2026.10.07/load_bad.csv`: 2초 행의 `force_N`을 빈칸, 3초 행의 `force_N`을 `abc`로 바꾼 오류 처리 테스트 파일입니다.
- `2026.10.07/load_result.csv`: 분석 실행으로 생성되는 유효 데이터와 `stress_Mpa` 결과 파일입니다.
- `2026.10.07/stress_plot.png`: 시간-응력 그래프 결과 이미지입니다.

#### 오늘 추가한 기능과 확인 내용

1. `pandas`로 CSV를 읽고 `force_N / 100`으로 응력(`MPa`)을 계산했습니다. 단면적은 `100 mm²`로 설정했습니다.
2. `time_s`와 `force_N` 중 빈칸 또는 숫자가 아닌 값이 있으면 CSV 행번호와 문제값을 알리고 해당 행을 계산과 그래프에서 제외합니다.
3. 제외 행 수와 유효 데이터 수를 출력하며, 유효 데이터가 없으면 계산을 중지합니다.
4. 각 데이터 점을 선으로 연결한 시간-응력 그래프를 만들고, 최대 응력점을 빨간색으로 표시해 시간과 응력값을 주석으로 표시합니다.
5. 기준 응력 `6 MPa`를 초과한 데이터 개수를 출력합니다.

정상 원본 데이터 실행 확인 결과:

```text
데이터 개수: 10개
최대 하중: 800 N
최대 하중 발생 시간: 5 s
최대 응력: 8.0 MPa
최대 응력 발생 시간: 5 s
기준 응력 6 MPa 초과 데이터 개수: 2개
```

오류 테스트 파일 실행 확인 결과:

```text
제외한 행: CSV 4행, force_N 문제값=빈칸
제외한 행: CSV 5행, force_N 문제값=abc
제외한 행 수: 2개
유효한 데이터 수: 8개
```
